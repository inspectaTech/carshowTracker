Free & Open-Source Options

OpenStreetMap (OSM): A community-driven, 100% free global dataset. It serves as the foundation for many other platforms like Mapbox and Radar.

Leaflet: A lightweight JavaScript library (approx. 42 KB) for rendering interactive maps. It is often paired with OSM tiles for a completely free setup.

OpenLayers: A more robust open-source library than Leaflet, capable of handling complex GIS tasks and multiple map providers.

MapLibre: An open-source fork of Mapbox GL JS (v1) that provides high-performance vector tile rendering without the licensing restrictions of newer Mapbox versions.
